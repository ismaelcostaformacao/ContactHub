# 📇 ContactHub

O **ContactHub** é uma solução web eficiente, segura e escalável, desenvolvida para permitir o **registo, consulta, atualização e remoção de contatos pessoais e profissionais**.  
Este documento apresenta o **contexto**, **objetivos**, **funcionalidades**, **arquitetura**, **tecnologias previstas** e os **artefactos essenciais** que orientam o desenvolvimento do sistema.

---
---

## 📘 Descrição do Projeto

O projeto visa disponibilizar uma solução web moderna e robusta, garantindo:

- Gestão completa de contatos  
- Interface intuitiva e responsiva  
- Elevado nível de segurança  
- Desempenho otimizado  
- Escalabilidade para grandes volumes de dados  

---

## 🎯 Objetivos

- Criar uma plataforma centralizada para gestão de contatos.  
- Garantir segurança e privacidade dos dados.  
- Oferecer uma experiência de utilização simples e eficiente.  
- Suportar crescimento e elevado número de utilizadores.  

---

## ⚙️ Requisitos Funcionais

- **Registo de novos contatos** com campos personalizáveis.  
- **Pesquisa e filtragem** por nome, categoria ou empresa.  
- **Atualização e remoção** de contatos existentes.  
- **Gestão de categorias** de contatos.  
- **Exportação de lista** para formatos **CSV** e **PDF**.  
- **Notificações automáticas por email**.  

---

## 🛡️ Requisitos Não Funcionais

- **Segurança:** autenticação e autorização baseada em papéis (RBAC).  
- **Desempenho:** tempo de resposta inferior a **2 segundos**.  
- **Usabilidade:** interface responsiva e compatível com dispositivos móveis.  
- **Escalabilidade:** suporte para até **10.000 contatos simultâneos**.  
- **Disponibilidade:** sistema online **24/7**.  

---

## 🧱 Arquitetura (Resumo)

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap.  
- **Backend:** Java Servlet.  
- **Base de Dados:** MySQL.  
- **Autenticação:** Java Servlet.  
- **Servidor Java-Web:** Apache Tomcat   

---

## 🧰 Tecnologias Previstas

- **Linguagens:** Java, JavaScript, SQL, JSP, HTML, CSS
- **Frameworks:** Bootstrap, Java Servelet
- **Ferramentas:** GitHub, Tomcat  
- **Formatos de Exportação:** CSV, PDF
